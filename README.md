 Instagram Analytics Project

## Tools Used

- MySQL
- Tableau

## Project Overview
This project analyzes Instagram content performance across different traffic sources.

## Business Questions
1. Which content categories perform best?
2. Which traffic sources drive engagement?
3. How does follower count affect performance?

## Key Findings
- Food and Comedy dominate Explore traffic.
- Technology performs best in External traffic.
- Music performs best in Reels Feed.
- Larger accounts generally achieve higher attention efficiency.
